# Databricks
Treinamento de databricks oficial 

Projeto de estudos em Databricks para Engenharia de Dados.
Este repositório reúne exercícios e práticas do treinamento Get Started with Databricks for Data Engineering, com foco em conceitos de Lakehouse, notebooks, Delta Lake, pipelines de dados e modernização de ETL. O objetivo é consolidar minha evolução técnica em Databricks, conectando minha base em integração de dados e ETL às práticas modernas de engenharia de dados.
